# 熔炼与进化

**熔炼（熔 MERGE）** 就是「循环引擎」：两张弱卡合成一张更强的卡。世界里的卡变少了
（**通缩**），而那些按铸造价卖不掉的「废卡」，被变成了**冲击稀有度的机会**。 `[proven]`

---

## 怎么运作

1. 玩家选**两张自己的卡**（都不能在质押中）。
2. 支付一小笔熔炼手续费（`mergeFee`）。
3. 两张卡被**烧掉**，生成**一张更高等级的卡**（进化）。

子卡会获得一个**新的 `seed`**（在后置阶段生成），所以**无法提前「试」出好组合**——
交易前不可能挑好一个划算的配对。 `[proven]`

```
base  = max(rankA, rankB)
child = 加权选择（以 base 为基准向上，带概率加成）   // 可能持平，极少情况会下降
以很小概率：child = 「空」（两张都烧掉，不出新卡）        // 防套利
```

---

## 「空熔」概率（dud）

有很小概率熔炼**「失败」**：两张卡烧掉，但**不出现**新卡。 `[proven]`

| 参数 | 默认值 | 含义 |
|---|---|---|
| `mergeFee` | **0.00002 ETH** | 熔炼手续费 |
| `mergeFailBps` | **700** | 7% 的「空熔」概率 |

「空熔」是**防套利**设计（堵住「N+1 永远比 2×N 划算」这一套利场景）。
若 `mergeFailBps = 0`，该概率被完全关闭。 `[proven]`

> [!NOTE]
> 说白了：熔炼不是「稳赚」，它有 7% 的概率两张全没。这正是它区别于「确定性兑换」的地方，
> 也让熔炼不能被当作套利机器。

---

## 为什么对玩家有价值（而不只是「倒掉」）

- **消化废卡。** 弱卡按铸造价卖不出去，与其压着，不如熔掉——熔炼是「从废料里长出稀有」的
  一次下注。 `[assumed]`
- **通缩。** 2→1 减少供应；最终发行量（8888）只会因销毁而减少。 `[proven]`
- **追稀有。** SR/UR/SSR 的组合是进化的目标。 `[assumed]`
- **数值进化。** 高一等级的子卡在战斗中更强、更耐打。 `[proven]`

---

## 不变量与安全

- 不能拿同一张卡和它自己熔炼（必须两张不同的卡）。 `[proven]`
- 不能熔炼不属于自己的、或处于质押中的卡。 `[proven]`
- 子卡 `seed` 在执行后确定——无法提前挑出稀有。 `[proven]`
- 操作是**原子**的（one-shot）：要么两张烧掉并出现新卡，要么（空熔时）两张烧掉且不出新卡，
  要么整笔交易被拒绝。 `[proven]`

---

## 参数（可通过 `Config` 调整）

| 键 | 默认 |
|---|---|
| `mergeFee` | 0.00002 ETH |
| `mergeFailBps` | 700（7%） |

---

## 示例（示意）

假设你手上有两张 R 卡：

```
rankA = R(1), rankB = R(1)   →  base = R(1)
child = 以 R 为基准，可能升到 SR / UR（带概率加成）
      或以 7% 概率「空熔」→ 两张都消失，没有新卡
```

> [!WARNING]
> 上例为**说明性**流程，不代表任何具体概率分布。真实分布以合约与公示的 pull-rate 为准。 `[assumed]`

---

## 小结

- 烧 2 张 → 铸 1 张更高等级的卡。手续费 `mergeFee`。 `[proven]`
- **7% 空熔**（`mergeFailBps = 700`）：两张都烧、不出卡，防套利。 `[proven]`
- 子卡 `seed` 后置生成，无法预先挑组合；操作原子。 `[proven]`
- 造成通缩，是「废卡 → 稀有」的进化通道。 `[proven]`
