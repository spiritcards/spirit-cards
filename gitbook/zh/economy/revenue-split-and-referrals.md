# 收入分配与推荐

这一页把**钱怎么分**讲透：项目手续费的固定分配、版税去向、决斗抽水的再分配，以及推荐机制
（含固定的「上级推荐 3%」）。所有比例都是中性、公开描述的——**没有隐藏扣费**。

> [!WARNING]
> 分发的一切都只是**项目真实收取手续费的一部分，且无任何保证**。手续费归零时，分发归零。
> 本页**不含任何 APY、收益率或「回本天数」**。见 [法律声明](../project/legal-disclaimer.md)。

---

## 1. 统一分配（split）

每一笔项目手续费（铸造、熔炼、卡包）按固定比例拆分： `[proven]`

| 比例 | 去向 | 参数 |
|---|---|---|
| **60%** | 分红池（质押者） | `poolBps = 6000` |
| **10%** | 推荐基金 | `referralBps = 1000` |
| **30%** | 国库（团队 / 市场） | `houseBps = 3000` |
| **0%** | 储备 | `reserveBps = 0` |

合计恒为 100%；可通过 `setSplit` 调整，但**必须等于 100%**。 `[proven]`

## 2. 版税（ERC-2981）

| 项 | 值 |
|---|---|
| 版税率 | **5%**（`royaltyBps = 500`） |
| 来源 | 卡牌**二级销售**（OpenSea） |
| 去向 | **国库**（不进分红池） |

版税相对稳定、不依赖新增铸造，是项目的少量常规收入。项目**没有** ERC-20 代币，**不用**
Uniswap / LP。 `[proven]`

---

## 3. 决斗抽水的再分配

决斗抽水 = 奖池的 **10%**（`pvpRakeBps = 1000`）。抽水再分： `[proven]`

| 抽水占比 | 去向 | 参数 |
|---|---|---|
| **70%** | 国库 | 抽水余额（`100% − 30%`） |
| **30%** | 分红池 | `rakeToPoolBps = 3000` |

抽水是**外部收入**（不来自铸造），因此决斗活跃度会为分红池补充进项。 `[proven]`

## 4. 推荐机制

推荐是**从被推荐人的行为中抽成**，**不是**从其存款抽成（经典的「从存款抽成」金字塔结构被排除）。 `[proven]`

### 规则

- 玩家可**一次性**设置推荐人；推荐人须**自己至少铸过一张卡**。 `[proven]`
- 推荐基金 = 手续费的 **10%**（`referralBps = 1000`）。它的分配： `[proven]`
  - **固定 3%（毛支付额）→ 上级推荐（master ref）**：`masterRefBps = 300`。
    这是对**每个付款人**都生效的固定「顶层」推荐。
  - **7% → 付款人自己的推荐人**。
- 若付款人**没有**推荐人，这 7% **留在未分配的基金**中，留待最终提取
  （`withdrawReferralLeftover`，**仅限未分配的剩余部分**）。 `[proven]`

### 拆解举例（支付 100 单位毛额）

```
毛支付额 = 100
├─ 3  → 上级推荐（master ref，固定，对每个付款人都收）
├─ 7  → 付款人自己的推荐人（若无推荐人，则留存于未分配基金）
└─ 90 → 进入统一 split：pool 60% / referral 10% / treasury 30% / reserve 0%
```

> [!NOTE]
> 上例只是**说明分配结构的算术**，不代表任何具体金额或收益。请勿据此推算收入。 `[assumed — 说明性示例]`

---

## 透明性声明

> [!NOTE]
> **上级推荐是固定的 3% 毛支付额，对任何付款人都收取。** 我们**中立、公开**地说明这一点，
> 就是为了避免任何隐性扣费。已计提给推荐人的份额（`referralOutstanding`）**受保护**，不能被
> 所有者当作「剩余」提走。 `[proven]`

---

## 推荐**不**是什么

- 推荐**不是**「邀请返息 / 拉人头分层」——它是**单层**设置，且只对**行为**抽成。 `[proven]`
- 推荐**不**来自被推荐人的**存款**（不存在所谓存款）。 `[proven]`
- 推荐**不**承诺任何固定收益。 `[proven]`

## 小结

- 统一分配：**pool 60 / referral 10 / treasury 30 / reserve 0**。 `[proven]`
- 版税 **5%** → 国库。 `[proven]`
- 抽水 **10%**，其中 **70% 国库 / 30% 分红池**。 `[proven]`
- 推荐基金 10%：**上级推荐固定 3% 毛支付额**，付款人自己的推荐人 **7%**；无推荐人则 7% 留存。 `[proven]`
- **无任何收益保证。** `[proven]`
