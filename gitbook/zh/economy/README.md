# 经济总览

Spirit Cards 是一款**游戏**，它的货币层建立在**项目真实收取的手续费**之上。这里**没有**
保证收益，也**没有**「存币生息」。凡是分发出去的东西，都只是**所收手续费中的一部分**。
下面讲清楚来源、去向与分配。 `[proven]`

> [!WARNING]
> 本页及全站**不出现任何 APY、收益率或「回本天数」数字**。分红池与国库只是「项目实际赚取的
> 手续费的一部分，且无任何保证」。手续费归零时，分发归零。见
> [法律声明](../project/legal-disclaimer.md)。

---

## 来源（sources）

| 来源 | 是什么 |
|---|---|
| **铸造** | 挖矿铸造卡牌的付款（按纪元价格 `eraPrice`） |
| **熔炼** | 熔炼手续费（`mergeFee`） |
| **卡包** | 卡包销售收入（含折扣） |
| **PvP 抽水** | 决斗奖池的 10%——**外部收入** |
| **版税** | 二级销售的 5%（ERC-2981）→ **国库** |
| **赞助 / 合作** | 外部注入（未来可能入池） `[planned]` |

---

## 去向（sinks）

| 去向 | 谁得到 |
|---|---|
| **分红池（pool）** | 质押者——按权重分配 |
| **推荐基金（referral）** | 推荐人（上级推荐 + 邀请人） |
| **国库（treasury）** | 团队 + 市场 |
| **储备（reserve）** | 程序化运营（`reserveBps = 0` 时未使用） |
| **卡牌销毁** | 熔炼（2→1）与对战（命归零）→ 供应减少 |

---

## 收入分配（split）

每一笔项目手续费按固定比例分配： `[proven]`

| 比例 | 去向 | 参数 |
|---|---|---|
| **60%** | 分红池（质押者分红） | `poolBps = 6000` |
| **10%** | 推荐基金 | `referralBps = 1000` |
| **30%** | 国库（团队 / 市场） | `houseBps = 3000` |
| **0%** | 储备 | `reserveBps = 0` |

四项之和 = 100%。分配可通过 `setSplit` 调整，但**必须恰好等于 100%**。 `[proven]`

> [!NOTE]
> 版税（5%）**不进**分红池，而是**直接进国库**。PvP 抽水里则有一部分进分红池（见下）。

---

## 版税（ERC-2981）

- **版税 = 5%**（`royaltyBps = 500`），来自卡牌的**二级销售**。
- 版税**进国库**，不进分红池——它是项目相对稳定、不依赖新增铸造的少量收入。 `[proven]`
- 卡牌交易发生在 **OpenSea**（Robinhood Chain 的原生市场）。项目**不使用** Uniswap / LP，
  也没有自己的 ERC-20 代币。 `[proven]`

---

## 分红池由什么填充

分红池（质押者分红）的进项： `[proven]`

1. 铸造手续费的一部分（60%）；
2. 熔炼手续费（60%）；
3. 卡包收入（60%）；
4. **PvP 抽水**（抽水的 30%）；
5. 外部注入（赞助） `[planned]`。

**版税不进来**——它是国库的。 `[proven]`

此外有一个免许可函数 `pumpPool()`：任何人都可以调用它，把 `accruedPool` 里累积的资金
注入 `StakeVault` 作为分红。资金**永远进金库**，**不会进调用者**的口袋。 `[proven]`

---

## PvP 抽水的去向

决斗抽水 = 奖池的 **10%**（`pvpRakeBps = 1000`）。抽水再按如下比例分： `[proven]`

| 抽水占比 | 去向 | 参数 |
|---|---|---|
| **70%** | 国库 | 抽水余额 |
| **30%** | 分红池 | `rakeToPoolBps = 3000` |

抽水是**外部收入**（不来自铸造），所以它给分红池补充了与二级/对战活跃度挂钩的进项。 `[proven]`
胜负是玩家之间**零和**（再加抽水），所以这不是什么金字塔结构。 `[proven]`

---

## 推荐基金

邀请是「被邀请人**行为**的一个百分比」，**不是**「从其存款抽成」。 `[proven]`

- 玩家可**一次性**设置推荐人（推荐人须自己至少铸过一张卡）。 `[proven]`
- 推荐基金（手续费的 10%）分配如下： `[proven]`
  - **固定 3% 的毛支付额 → 上级推荐（master ref）**（对**每个**付款人生效的固定「顶层」推荐）；
  - **7% → 付款人自己的推荐人**。
- 若付款人**没有**推荐人，这 7% **留在未分配的基金**里，待最终提取（`withdrawReferralLeftover`，
  仅限未分配的剩余部分）。 `[proven]`

已计提给推荐人的份额（`referralOutstanding`）是**受保护**的，不能被所有者当作「剩余」提走。 `[proven]`

> [!NOTE]
> **透明性。** 上级推荐是**固定的 3% 毛支付额**，对**任何**付款人都会收取。我们**中性地、
> 公开地**说明这一点，避免任何隐性扣费。见
> [收入分配与推荐](revenue-split-and-referrals.md)。

---

## 诚实的数学，不含承诺

- **分红池份额与活跃度绑定。** 没有手续费 → 没有进项 → 分发下降直至为零。这是诚实的
  revenue-share，不是庞氏。 `[proven]`
- **没有任何 APY、收益率或「回本期限」。** 项目不发布、不保证。
- **没有保证收益。** 团队没有回购承诺。
- **没有「存款利息」。** 推荐只来自行为。
- **没有手动拉盘、没有刷量。** 一切池操作都是程序化、来自真实收入。 `[proven]`

---

## 可调性（Config）

所有关键经济参数**不是代码常量**，而是 `Config` 里的旋钮（所有者 = 多签 Safe，未来加
timelock）：`poolBps`、`referralBps`、`houseBps`、`reserveBps`、`royaltyBps`、`masterRefBps`、
`pvpRakeBps`、`rakeToPoolBps`、价格、费用等。可**无需重新部署**修改。 `[proven]`
