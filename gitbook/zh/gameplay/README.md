# 玩法总览

除了「挖矿 / 熔炼 / 对战 / 质押」这条经济主循环，游戏还有一层**进度与竞争**玩法：**链上活跃积分**
和**赛季排行榜**。它给玩家一个「持续回来玩」的理由，也是「攀比」这种社交驱动力的载体。 `[proven]`

> [!NOTE]
> **积分没有货币价值**，不能兑换成钱。赛季奖励是皮肤 / 物品，**不是钱**。见
> [法律声明](../project/legal-disclaimer.md)。 `[proven — 设计不变量]`

---

## 两层玩法

| 层 | 内容 | 状态 |
|---|---|---|
| **积分（链上）** | 挖矿 / 熔炼 / 质押 / PvP 胜利 → 活跃积分 | `[proven]` |
| **排行榜（链上读取）** | 从 `Points` 合约读取名次 | `[proven]` |
| **赛季（链下）** | 按快照划分的竞争窗口 | `[planned]` |
| **赛季奖励** | 皮肤 / 唯一物品（非货币） | `[planned]` |

---

## 积分怎么来

| 动作 | 积分 | 参数 |
|---|---|---|
| 挖矿 MINE | 1 | `pointsMine` |
| 熔炼 MERGE | 2 | `pointsMerge` |
| 质押 STAKE | 2 | `pointsStake` |
| PvP 胜利 | 3 | `pointsPvpWin` |

积分由授权模块（`SpiritCards`、`StakeVault`、`Battle`）通过 `Points` 合约记账。 `[proven]`

> [!NOTE]
> 上个项目**没有**把质押计入积分，惹恼了持有者。这里做了修正：`StakeVault` 为质押发放积分
> （批量操作时按卡数 ×N）。 `[proven]`

---

## 为什么这对玩家有意义

- **留存** —— 每天都有回来的理由。 `[assumed]`
- **攀比** —— 名次公开展示，激励竞争。 `[assumed]`
- **传播** —— 进度和名次便于分享。 `[assumed]`

---

## 赛季不会清空你的收藏

> [!NOTE]
> 赛季**只重置排行榜**（链下快照），**不会**让卡牌「退役」或离开游戏。你挖到的卡**永久保留**。
> 这是与「卡池轮换」类玩法的关键区别。 `[proven — 设计决策]`
