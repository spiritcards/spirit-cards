## 这是什么

**Spirit Cards**（代币符号 `SPC`；链上 `name() = "Spirit Cards"`，`symbol() = "SPC"`）是一款「卡牌收藏 + 对战」游戏。卡牌不是
在商店里按固定价格出售，而是**靠挖矿获得**：你的设备不断尝试一个数字（`nonce`），直到算出的
哈希满足难度门槛（前导零比特数足够）——这就是货真价实的工作量证明（PoW），和比特币同理，
但在 Robinhood Chain 上只需几秒和几厘 Gas。每张卡都有**属性（元素）、稀有度和战斗数值**，
全部由它的链上「种子」（`seed`）确定性推导，任何人都能复算验证。

拿到卡之后，它进入一个循环：**熔炼**（2 合 1 进化）、**上决斗场押注**、**放进质押金库存着**、
**争夺积分榜**。所有核心参数都是 `Config` 合约里的**可调旋钮**，由多签持有者管理，因此平衡性
可以在不重新部署合约的情况下调整。

## 游戏循环

```
挖 MINE  →  熔 MERGE  →  ⚔ BATTLE  →  押 STAKE  →  榜 POINTS  →  循环
 挖矿        熔炼          对战          质押          积分
```

| 环节 | 玩家做什么 | 会发生什么 |
|---|---|---|
| **挖 MINE** | 点「挖矿」，等待找到 `nonce`，支付当前纪元价格 | 得到一张带属性/稀有度的卡 + 1 个筹码（筹码让下一次铸造 −30%） |
| **熔 MERGE** | 烧掉 2 张卡 | 得到 1 张更高等级的卡（进化）。有 7% 概率「空熔」（两张都烧掉、不出卡） |
| **⚔ BATTLE** | 用一张卡 + ETH 押注，对战另一张卡 | 赢家拿走奖池减抽水；输家失去 **3 条命中的 1 条**，命归零则卡被销毁 |
| **押 STAKE** | 把卡存进金库，选 0 / 7 / 30 / 90 / 180 / 365 天 | 按权重获得分红池份额；质押中的卡也能参战 |
| **榜 POINTS** | 游戏并竞争 | 累积链上活跃积分；赛季排行榜 |
