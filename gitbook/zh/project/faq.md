# 常见问题 FAQ

下面列出玩家最可能提出的问题。答案反映**当前状态**（t8）。参数可调，可能会变化。

---

**1. 用一句话说，Spirit Cards 是什么？**

一款「灵兽卡牌」游戏。卡不能在商店买——必须**挖矿**得到（找 `nonce`，类似比特币但只需几秒）。
之后可以熔炼、押注对战、放进质押金库、争夺积分榜。

**2. 在哪条链上？怎么付费？**

**Robinhood Chain**（Arbitrum Orbit L2）。当前线上部署在**测试网 `chainId 46630`**（演练栈
t8，2026-10-04）；主网 `4663` 为目标，**尚未部署**。Gas 与支付都用 **ETH**。

**3. 「挖矿」是真的 PoW 吗？**

是。设备搜索 `nonce`，使
`keccak256(chainId ‖ contract ‖ miner ‖ nonce)` 的前导零比特数达标。合约会校验。
浏览器与 CLI 挖矿器算出的 `work` 与链上事件 `Mined` **逐字节一致**。 `[proven]`

**4. 难度会涨吗？会把我挤走吗？**

**没有棘轮。** 难度只随价格纪元温和上升（**每纪元 +0.33 位**）。节奏由协议（发行闸门 + 价格）
控制，不是算力竞赛。矿场更快，但**每张卡的奖励一样**。 `[proven]`

**5. 总共有多少张卡？**

上限 **8888**（`maxSupply`），最终发行量，只减不增。 `[proven]`

**6. 什么是筹码（chip）？**

**全价铸造**发放 **1 个筹码**（ERC-1155）；筹码让**下一次**铸造 **−30%**，并被**消耗**。 `[proven]`

**7. 熔炼失败了会怎样？**

有小概率（**7%**，`mergeFailBps`）「空熔」：两张卡都烧掉、不出新卡。这是**防套利**设计。 `[proven]`

**8. 质押分红是保证收益吗？**

**不是。** 质押给的是**分红池份额**，而分红池由**真实手续费**填充。没有手续费就没有进项。
项目**不发布、不保证**任何 APY、收益率或「回本期限」。见 [法律声明](legal-disclaimer.md)。 `[proven]`

**9. 我能拿多少质押收益？多久回本？**

项目**不发布**收益率，也不发布回本期限——这**无法保证**。界面上可能有「投入 / 取得」的
历史指示（来自链上的历史记录），但那**不是**承诺。 `[proven]`

**10. 对战是怎么打的？公平吗？**

托管式押注决斗：双方各押一张卡 + **等额** ETH。结果受**数值、元素（±20%）、技能、每场攻击
浮动（±40%）**影响。结算确定性可复现；随机性来自 `acceptDuel` **执行区块的 `prevrandao`**，
接受方**签名时未知**。数值接近的卡 ≈ 五五开。 `[proven]`

**11. 我会失去卡吗？**

会。输家失去 **3 条命中的 1 条**；**命归零则卡被销毁**。此外，输家还会失去押注。 `[proven]`

**12. 质押中的卡能参战吗？**

能。卡留在金库，只在决斗期间被锁定；质押者**继续吃分红**；**无需** NFT 授权。 `[proven]`

**13. 5% 版税是什么？去哪了？**

ERC-2981 版税，来自 OpenSea 二级销售；**进国库**（不进分红池）。 `[proven]`

**14. 推荐怎么运作？**

你**一次性**设定推荐人（推荐人须自己铸过卡）。推荐基金里，**3% 毛支付额**给固定的**上级推荐**，
**7%** 给你的推荐人。若无推荐人，那 7% 留在未分配基金。这是对**行为**的百分比，不是对存款。 `[proven]`

**15. 积分能换钱吗？**

不能。积分是游戏内活跃度指标（挖矿 / 熔炼 / 质押 / PvP 胜利），链上存储，赛季排行榜。
**没有货币价值。** 赛季奖励是皮肤 / 物品，**不是钱**。 `[proven]`

**16. 安全吗？有审计吗？**

有内部安全评审和 **418/418 测试**（fuzz + 不变量）。所有者 = **Safe 2-of-3**，关键函数有
`ReentrancyGuard`，有 `paused` 刹车，`unstake` 不暂停。当前阶段**未计划付费外部审计**。
**任何审计都不消除风险**——这是实验。 `[proven]`

**17. 没有钱包怎么进？**

计划两种方式：普通钱包（MetaMask / OKX）与「一键」内嵌钱包（Face ID / 邮箱、无需助记词，
通过 Privy）。 `[planned]`

**18. 为什么是 Robinhood Chain？**

低 Gas、原生 OpenSea、开箱即用的账户抽象（ERC-4337）、以及品牌认知。 `[assumed]`

**19. 赛季会清空我的收藏吗？**

不会。**赛季只重置排行榜**，卡牌、稀有度、战绩、编号**永久保留**。 `[proven]`

**20. 卡包有什么限制？**

面向中国渠道（适用范围内）：**不售予 18 岁以下**、**公示概率**、
无彩票式价值差。 `[assumed — 产品 / 合规要求]`
