# 对战机制

这一页讲决斗的**完整生命周期**：创建、接受、取消，托管（escrow）如何运作，以及质押中的卡如何
参战。所有链上函数名保留英文。

> [!WARNING]
> 对战是押注机制。**你可能输掉押注和卡牌。** 见 [法律声明](../project/legal-disclaimer.md)。

---

## 三个核心函数

| 函数 | 谁调用 | 作用 |
|---|---|---|
| `createDuel(cardA, stake)` | 挑战者 A | 托管卡 A + 押注 `stake`，创建**公开决斗** |
| `acceptDuel(id, cardB)` | 接受者 B | 托管卡 B + **等额**押注，**立即结算** |
| `cancelDuel(id)` | 创建者 A | 取消自己的公开决斗，退回卡 A + 押注 |

全都是链上原子操作。 `[proven]`

---

## 生命周期

### 1. 创建（`createDuel`）

- A 选择一张**自己的卡**（可在质押中）和一笔押注 `stake`（必须 > 0）。
- 合约把卡 A **托管**，并收取 A 的押注。
- 生成一个**公开的**决斗，任何符合条件的玩家都能看到并接受。 `[proven]`

### 2. 接受与结算（`acceptDuel`）

- B 选择一张自己的卡 + **相同金额**的押注。
- 合约把卡 B 托管，收取 B 的押注，然后**在同一笔交易里立即结算**战斗。 `[proven]`
- 结算后：
  - **赢家**拿走 `pot − 抽水`（`pot = 2 × stake`），并**取回**自己的卡；
  - **输家****取回**自己的卡，但**失去 1 条命**，押注归赢家；
  - 若输家命归零 → 卡被**销毁**。 `[proven]`

### 3. 取消（`cancelDuel`）

- 只要还没被接受，创建者可以取消，卡与押注**原样退回**。 `[proven]`

---

## 托管（escrow）与质押卡

- **普通卡**：决斗期间卡被合约托管，不能转卖；结算后归还赢家、输家取回（或被销毁）。 `[proven]`
- **质押中的卡**：卡**不离开金库**，只是在决斗期间被**锁定**（`lockForBattle`）。 `[proven]`
  - 质押者**继续**获得分红；
  - **无需** NFT 授权（approve）；
  - 若卡在战斗中失去最后一条命，金库自行**销毁**它，并为质押者结算**未领取的奖励**
    （`killInBattle`）。 `[proven]`

> [!NOTE]
> 「质押中也能参战」是这款游戏的一个卖点：让**持有的卡同时具备生产力与战斗力**，而不必在
> 「存着吃分红」和「拿去打」之间二选一。

## 硬性规则

| 规则 | 说明 |
|---|---|
| 押注 > 0 | 双方都必须押注，且**金额相等** |
| A ≠ B | 不能接受自己的决斗 |
| 卡必须是自己的 | 参战的卡属于调用者（或由其质押） |
| 卡不能已被托管 | 一张卡不能同时出现在两个决斗里 |
| 命 > 0 才能参战 | 命为 0 的卡已被销毁，无法参战 |

以上均为合约不变量。 `[proven]`

---

## 结算何时确定

- `acceptDuel` 执行的**那一区块**决定结果。随机源是**执行区块的 `prevrandao`**。 `[proven]`
- 接受者**在签名时**并不知道该值——所以无法选一个稳赢的时机。 `[proven]`
- 结算**确定性且可复现**：给定双方卡的 `seed`、押注和执行区块的 `prevrandao`，任何人都能
  **离线重放**结果。 `[proven]`

## 事件（events）

合约发出（用于 UI / 重放 / 索引）： `[proven]`

| 事件 | 含义 |
|---|---|
| `DuelCreated(id, a, cardA, stake)` | 公开决斗已创建 |
| `DuelResolved(id, winner, winCard, loseCard, payout, rake)` | 战斗已结算 |
| `DuelCancelled(id, a, cardA, stake)` | 决斗被创建者取消 |
| `CardBurned(card, owner)` | 卡被销毁（命归零） |
| `DuelDetail(id, elA, elB, skA, skB, aWins)` | 富化结果，供 UI / 重放（含元素与技能） |

## 参数（可通过 `Config` 调整）

| 键 | 默认 |
|---|---|
| `lives` | 3 |
| `pvpRakeBps` | 1000（10%） |
| `rakeToPoolBps` | 3000（抽水的 30% → 分红池；70% → 国库） |
| `typeAdvBps` | 2000（元素 ±20%） |
| `atkVarianceBps` | 4000（每场攻击浮动 ±40%） |

---

## 小结

- `createDuel` 托管卡 + 押注；`acceptDuel` 等额押注并**立即结算**；`cancelDuel` 退回。 `[proven]`
- 质押中的卡可参战（锁定、继续分红、免授权）。 `[proven]`
- 结果由执行区块的 `prevrandao` 决定，接受方签名时未知。 `[proven]`
