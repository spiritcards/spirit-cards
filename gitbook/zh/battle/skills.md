# 技能

每张卡有 **6 种技能**中的一种（或「无」）。技能由种子决定，**玩家无法自行选择**。技能在战斗中
提供特殊效果，是除元素之外的第二层「运气 + 策略」因素。 `[proven]`

---

## 技能表

| # | 技能 | EN | 效果 |
|---|---|---|---|
| 0 | 无 | none | 无效果 |
| 1 | 暴击 | crit | **20%** 概率造成 **×2** 伤害 |
| 2 | 护盾 | shield | 受到的伤害 **−30%** |
| 3 | 穿透 | pierce | **无视**对方 DEF |
| 4 | 精准 | precision | 始终 **+15%** 伤害 |
| 5 | 坚韧 | vigor | 最大生命值 **+20%** |

`[proven]`

---

## 逐个说明

### 0 · 无（none）

没有任何特殊效果。**不是坏事**——这类卡通常以纯数值说话，不吃技能的随机性，表现稳定。

### 1 · 暴击（crit）

- 每次该卡**发动攻击**时，有 **20%** 概率打出 **×2** 伤害。
- 概率逐次独立触发：一场多回合的仗里，理论上可以多次暴击。
- 期望伤害提升约为 `1 + 0.2 × (2 − 1) = 1.20`（即**约 +20% 的期望攻击收益**）。 `[assumed — 由概率推导]`

### 2 · 护盾（shield）

- 该卡**受到**的一切伤害（经前面所有修正后）**再乘 ×0.7**（−30%）。
- 对「挨打方」是通用减伤，对付高 ATK 或克制它的对手尤其有效。
- 与元素的「被克制 −20%」会**叠加**（乘法）。 `[proven]`

### 3 · 穿透（pierce）

- 该卡攻击时**无视**对方 DEF。
- 在公式里就是**跳过 `− DEF / 2` 这一步**。 `[proven]`
- 对付高 DEF 的对手（如高稀有度卡）格外强。

### 4 · 精准（precision）

- 该卡**每次**攻击**始终** +15% 伤害（稳定，不随机）。
- 与浮动相乘。它不改变波动范围，只整体抬高你的输出。 `[proven]`

### 5 · 坚韧（vigor）

- 该卡**最大生命值 +20%**。
- 不改变每击伤害，只让你**更耐打**、能多撑几回合——对浮动大的近战尤其有价值。 `[proven]`

---

## 技能从哪里来

技能由种子推导：

```
skill = (seed >> 208) % 6
```

所以技能和稀有度、元素、数值一样，**是铸造时就固定的**，玩家不能洗点或替换。 `[proven]`

> [!NOTE]
> 具体位偏移（`>> 208`）是当前实现值，以链上合约为准。 `[assumed — 偏移量为实现细节]`

---

## 技能的组合效应

技能会与元素、浮动**相乘叠加**，因此单张卡可能同时具备多重优势或劣势：

| 组合 | 效果直觉 |
|---|---|
| 护盾 + 元素克制 | 对手本就 ±20%，再被 ×0.7 → 极其耐打 |
| 暴击 + 元素克制 | 高期望爆发（克制 ×1.2 与暴击 ×2 相乘） |
| 穿透 + 高 ATK | 无视 DEF，直接猛击低 HP 目标 |
| 精准 + 高浮动 | 稳定抬输出，减少「打太软」的回合 |
| 坚韧 + 高 DEF | 拖入消耗战，让对手的暴击更难一击致命 |

`[assumed — 机制组合的定性描述]`

> [!WARNING]
> 上表是**定性直觉**，不是胜率承诺。真实结果仍由每回合的随机浮动决定。见
> [完整战例](worked-examples.md)。

## 技能在伤害公式里的位置

```
1) ATK × 元素倍率
2) × 每场攻击浮动 [0.6, 1.4]
3) − 防守方 DEF / 2           ← 攻方有「穿透」则跳过
4) 应用技能修正:
   - 攻方「暴击」命中 → ×2
   - 攻方「精准」     → ×1.15
   - 守方「护盾」     → ×0.7
   （最终取整数，至少为 1）
```

「坚韧」不在单次伤害里，而是在**战斗开始时**提高最大 HP。 `[proven]`

## 小结

- 6 种技能：无 / 暴击 / 护盾 / 穿透 / 精准 / 坚韧。 `[proven]`
- 技能由种子决定，不可选、不可换。 `[proven]`
- 与元素、浮动叠加，是「以弱胜强」和「强卡翻车」的重要来源。 `[proven]`
- **不是胜率保证**——一切仍受随机浮动影响。 `[proven]`
